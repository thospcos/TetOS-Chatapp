🛰️ TetOS Chatapp

TetOS Chatapp is a simple real-time chat application built with Node.js, Express, and Socket.IO.
It lets multiple users chat instantly using WebSockets.

⭐ Features

Real-time messaging

Username support

Clean and minimal UI

No database needed

Works locally or online (with Node hosting)

📦 Files Included
server.js
package.json
public/
 ├─ index.html
 ├─ chat.js
 └─ style.css

▶️ How to Run
1. Install dependencies
npm install

2. Start server
node server.js

3. Open browser
http://localhost:3000

🌐 Deployment

GitHub Pages will not run server.js (Node.js is not supported).
To make TetOS Chatapp work online, deploy using:
